# mambo-trader · 大A整活实验室

给 AI 一千万虚拟资金，用 MCP 选股、模拟交易、复盘，再用曼波配音记录它交了多少学费。

真实参考行情 + 1000 万虚拟本金 + Agent/MCP + 可审计账本 + Concat 自动生成 B 站日报素材。

**只做模拟交易，不连接任何真实券商。**这是独立编写的轻量首版，并非前面调研项目的官方客户端或已验证盈利策略。

## 一分钟本地启动

安装 Node.js 22 或以上版本，下载并解压项目，在目录内运行：

```sh
npm ci --ignore-scripts
npm start
```

打开终端打印的网址，默认 http://127.0.0.1:4173 。唯一运行依赖为 `@resvg/resvg-js`，用于本地绘制视频画面。初次下载后需先安装依赖。

Windows 也可以双击 `启动实验室.cmd`。关闭进程后停止行情刷新和撮合；重新启动会继续读取账本，但不会伪造离线期间的成交。

## 首版已经实现

- 账户初始本金固定为 **10,000,000 元虚拟人民币**；可创建最多20个独立账户。
- 自选池、真实参考报价、限价模拟委托、撤单、持仓、成交记录、含费用的净值与收益。
- 观察池支持沪深主板、创业板、科创板和北交所（60/00/30/68/43/83/87/88/92），初始6只为界面示例，不是推荐名单。自选池首版最多30只。模拟交易暂仅支持沪深主板普通股票（60/00）；ST可观察但不交易。指数交易、ETF、融资融券或做空暂不支持。
- 连续竞价时段、新鲜行情、T+1 可卖批次、100股整手、现金及待卖持仓冻结、涨跌停保守拒绝撮合。
- 模型支持 Chat Completions 兼容接口。填写自己服务商的根地址、准确模型 ID、API Key。模型请求会产生自己的API费用。
- 模型记录请求和返回的模型标识、数据快照、策略版本、结论、5交易日主观收益情景。**模型不自动下单**，可把建议带入委托表检查后提交。
- 模型擂台：独立账户、相同初始本金。账户创建日期不同和演示模式都要考虑，收益排序不等于严格的模型能力排名。
- 口播文案、JSON账本导出、浏览器生成12秒无配音竖版WebM字幕视频（720×1280）。视频可导入剪辑软件转MP4与补配音。
- 真实行情模拟与合成行情演示分开。模型与账户无历史记录时展示为空，不补画收益、不编造预测。

## Agent / MCP：不需要另填模型 API

启动网页后台后，把本项目作为 STDIO MCP 加到正在使用的 Agent：

```sh
codex mcp add mambo-trader -- node /你的项目绝对路径/mcp-server.mjs
```

Windows 请使用实际绝对路径。其他 MCP 客户端配置同样的命令和参数即可；默认连接 `http://127.0.0.1:4173`，可用 `ARENA_URL` 更改。应用有 `APP_API_TOKEN` 时，为 MCP 设置对应 `ARENA_TOKEN`，不要提交令牌。

工具：`market_state` → `research_context` → `record_analysis` → 按需要 `place_paper_order` / `cancel_paper_order` → `generate_daily_video` → `video_job_status`。快照30分钟有效、只能提交一次；分析不自动下单。Agent须如实自报身份，无法获得底层模型ID时明确标注未提供。

策略详见 [docs/AGENT_WORKFLOW.md](docs/AGENT_WORKFLOW.md)。`patient-v1` 低频、分散、允许空仓；MCP 买单计入持仓和待成交买单后，限制单只20%、合计60%。这是实验初始规则，不是经回测证明的盈利策略。网页仍可选择兼容 API 分析，属于可选方式。

## 一键生成曼波视频

1. 从 [Concat 官方 Releases](https://github.com/jub0t/Concat/releases) 安装桌面版本（已对 v0.2.8 验证）；找不到程序时设置 `CONCAT_BIN` 为可执行文件绝对路径。
2. 打开网页“收益日记”，点击“生成曼波配音 MP4”。也可运行 `npm run video`，或让 Agent 调用 `generate_daily_video`。
3. 等待进度完成，在网页预览并点击“下载 MP4”。下载使用附件响应；视频存放在本机 `data/videos/<任务ID>/daily.mp4`，即使浏览器不支持下载，也可直接复制该文件。

每条包含：用户固定片头、必剪内置“曼波”、模型及分析时间、事前主观预测、实际模拟账本、自嘲与结尾“不构成投资建议”。缺记录会如实做开张篇。画面720×1280、24fps、H.264/AAC MP4；同时保留 SRT、WAV、口播、发布文案、输入快照和可编辑 Concat 工程。字幕按句长估算时间，非逐字强制对齐。

**数据流**：口播文本发送到必剪在线接口，适配参考社区 [bcut-asr TTS 提案](https://github.com/SocialSisterYi/bcut-asr/pull/14)，它不是稳定承诺的官方开放SDK，接口变化或风控时会报错，不冒用其他音色。随后画面、字幕和音频由本机 Concat MCP 合成；固定口播缓存，避免重复合成。

## B站投稿与集数

“收益日记”可设置本期集数，从001开始，同一账户同日重做保留集数，下一日期自动递增。标题、片头和横版封面同步；合集名称“给AI一千万，看它交学费”。

已接入 [biliup](https://github.com/biliup/biliup)。安装 `@biliup/cli` 后设置 `BILIUP_BIN` 为二进制绝对路径（本机也自动查找项目同级 `tools/biliup` 下 Windows x64 版本）。打开“发布到B站”→扫码登录→检查程序填写的标题、简介、标签和封面→确认投稿。可开启“允许每日任务无人值守投稿”，Agent之后用 `publisher_status` 和 `publish_daily_video`。新安装默认关闭无人值守；公开投稿仍需平台审核，提交成功不代表审核通过。登录失效或平台接口变化需要处理。

二维码由本机 biliup 获取；凭据由 biliup 保存在忽略的 `data/`，不上传 GitHub，也不从浏览器提取 Cookie。内置辅助服务只监听 `127.0.0.1:19159`，不向公网开放。`data/publisher.json` 保存本机投稿开关及凭据文件位置，`data/uploads.json` 记录已提交任务，避免重复任务投稿。

如果浏览器下载不便，可点“保存到电脑‘下载’文件夹”，文件会保存在运行本地服务的电脑 `Downloads/大A整活实验室-成片/`。远程部署时该按钮保存到服务器，不是访问者的电脑；访问者应使用浏览器下载。

## 定时复盘与反馈

代码本身不会在关闭电脑时自行研究或交易。可让支持定时执行的 Agent 每日调用 MCP；当前工作流建议北京时间收盘后16:10，休市或行情日期未更新时跳过。定时任务属于本机 Agent 设置，不随 GitHub 代码自动安装；运行时需要电脑和 Agent 在线。

复盘关注累计样本、成本和风险，保留原预测，修改只创建下一版策略，禁止为了正反馈每天迎合最后一次盈亏。尚未实现5交易日预测自动到期结算，不报告虚构准确率；结果还需核对公司行为和数据缺失。

## 真实行情、费用与边界

参考行情来自 `https://qt.gtimg.cn`，保留来源、行情时间和获取时间。免费源可能延迟或中断，不等同交易所授权实时数据。

只有北京时间工作日 09:30–11:30、13:00–14:57 的连续竞价窗口且报价时间距当前不超过120秒才撮合。法定节假日依靠行情时间和有效成交量进一步拒绝成交；首版没有独立的完整节假日日历。集合竞价不撮合。休市下单为待执行委托，不会用当天旧价追记成交。

模拟成交价 = 参考价 ± 5bp滑点，仍必须满足用户限价。单笔数量限制在已观察到的累计成交量的0.1%以内；这是简化规则，并非真实盘口排队或市场冲击模型。涨跌停附近买入/卖出分别保守不成交。委托保留到撤销，属于软件自己的持续委托，并非券商日内有效订单。

费用为**模拟假设**：佣金万2.5、最低5元；卖出印花税万5；过户费十万分之一。这不是任何真实券商的报价。参数位于 `public/engine.mjs`。请勿中途改变历史成本口径而不标记版本。

当日盈亏相对前一个记录日快照；首日相对初始本金。账户估值包含浮动盈亏，快照为参考行情估值、并非交易所正式日终结算。缺报价持仓临时按成本显示并明确标记，遇到缺价不生成净值快照。暂不自动处理分红、送转、配股、拆合股；遇到除权事件需暂停实验并核对账本。

## 数据与密钥

- 账本在 `data/ledger.json`，已加入 `.gitignore`。迁移前停止服务并备份整个 `data/` 目录。
- API Key 只保留在浏览器内存和本次后端请求中，不存入账本或localStorage；刷新页面需重新填写。模型端点由用户自行确认，分析快照发送到所填服务商。
- 本机模式默认只监听 `127.0.0.1`。如要外网部署，必须设置 `APP_PASSWORD`，浏览器通过HTTP Basic认证访问，用户名可任意。外网请使用HTTPS反向代理。
- 这是**个人 / 同一受信任用户组**的应用，不是多租户服务。共享一个部署和密码的人能看到同一账本。其他人应下载项目自行运行，拥有各自数据和模型。

## 自己的 AI App / Agent 接入

你自己的程序可以直接调用模拟交易接口。设置 `APP_API_TOKEN` 后，可以用 `Authorization: Bearer <你的token>` 访问，无须把网页密码交给AI工具。公网服务需同时设置 `APP_PASSWORD`。

1. `GET /api/state`：取得账户ID、自选池、报价、持仓、净值、委托与模型记录。
2. `POST /api/watchlist`：`{"symbol":"600036"}` 加入股票。
3. `POST /api/orders`：下面是限价模拟订单。必须使用第一步取得的真实账户ID。

```json
{
  "accountId": "从 /api/state 获取的账户ID",
  "symbol": "600036",
  "side": "BUY",
  "qty": 100,
  "limit": 40.00,
  "source": "my-own-agent-v1"
}
```

4. `POST /api/cancel`：`{"accountId":"...","orderId":"..."}`。
5. `GET /api/export`：导出完整实验数据。
6. `POST /api/analyze`：`{"accountId":"...","baseUrl":"https://服务商/v1","model":"服务商模型ID","apiKey":"用户自己的密钥","strategyVersion":"v1"}`。仅分析，不执行订单。

POST 请求必须使用 `Content-Type: application/json`。接口永远只影响虚拟账户。应用令牌不要放进公开网页源码或提交到Git。

## GitHub 发布的两种方式

### A. 发布完整应用（真实行情 + 模型 + 共享持久账本）

代码推到自己的 GitHub 仓库，部署到可运行 Node.js 的服务或自己的服务器。

- 启动：`node server.mjs`
- Node版本：22+
- 环境变量：`HOST=0.0.0.0`、`PORT=平台端口`、`APP_PASSWORD=自己设置的强密码`
- **持久磁盘**：把 `DATA_DIR` 指向平台持久卷，避免重部署丢账本。不要把账本放在临时容器文件系统。
- Docker 镜像已提供；也可以直接下载ZIP在电脑运行。

每个下载者自己部署，默认获得各自的1000万虚拟账户。代码托管在GitHub不代表必须使用GitHub Pages运行后端。

### B. GitHub Pages 静态预览

已附 `.github/workflows/pages.yml`。推送后在仓库 Settings → Pages → Source 选择 GitHub Actions，可发布 `public/`。

**Pages不运行Node后台**：静态站仅提供明确标注的合成行情演示，账本在浏览器本地，不提供真实行情和模型代理。请勿将其演示收益当作实验结果发布。

## 每日实验与视频

每天可人工打开页面：刷新行情 → 让各模型对同一股票池分析 → 检查并提交模拟委托 → 收盘复盘 → 收益日记导出文案/账本/视频。

已保存的预测不可在界面中改写。调整策略应填写新版本。**5个交易日预测到期自动结算尚未实现**。Agent可通过本机定时任务调度研究、模拟委托与视频，但不保证无人值守成功；登录、外部接口、电脑休眠会影响运行。GitHub Actions不运行本机Concat，也不是交易所级准点服务。
