# 大A整活实验室：Agent 工作流

先启动网页服务，再用本项目 `mcp-server.mjs`。不需要再次调用任何模型 API；当前 Agent 直接完成研究和留档。MCP 是工具连接，不是凭空生成股票观点的模型。

## patient-v1：低频、分散、允许空仓

1. `market_state` 确定账户为真实参考行情的虚拟账户；不得把 DEMO 混进市场业绩。账户固定1000万初始虚拟资金，不能重置亏损。
2. `research_context` 取得带时间的不可变快照（30分钟有效）。先核对实际北京时间、报价时间、有效交易时段。休市可以研究，不能用旧价补记交易。
3. 先检查资料。仅有当天报价不能证明趋势、估值或基本面，不能据此编造历史指标、新闻、盈利能力。要形成买入判断，阅读并引用公司公告及可核验的历史价量数据，明确数据截至时间；无法验证则空仓观察。
4. 首个实验策略偏低频：每次最多3只，单只目标仓位最多20%，总仓位最多60%，不融资、不做空。优先有充分信息和流动性的普通主板股票。首版不支持其他板块模拟交易及ST交易。参考quote volume仅为累计量，不是可成交盘口。
5. `record_analysis` 保留实际模型/Agent标识、策略版本、快照、结论和来源。没有确定底层模型ID时明确写“未提供”，不能猜。候选可以为空，预测是5个交易日主观区间，不能包装为校准概率或承诺。提交不会自动下单。
6. 有足够依据且符合用户授权时才 `place_paper_order`。同一标的先查已有委托和持仓，避免重复下单；遵守100股、T+1、限价、新鲜行情、模拟费用和仓位上限。这里只影响虚拟账本。
7. 收益变动、交易成本、观察失败和下一步策略变更要留档，不改写已有预测。新策略用新版本；按样本外后续表现比较，不因某一天盈亏宣布策略有效。
8. `generate_daily_video` 再轮询 `video_job_status`。固定用户确认的片头、曼波音色、结尾“不构成投资建议”。视频采用反差开场→模型及资料时间→事前预测→实际账本→自嘲收尾。预测与收益分开，资料不足如实说。同一账户同日重做保留集数。
9. `publisher_status` 检查扫码登录状态与 `autoPublish`。只有用户已开启无人值守时才 `publish_daily_video`。等待提交结果，核对稿件列表和BV，不把提交待审说成审核通过。账号失效、验证码、上传失败时通知用户，不绕过验证，不自动重复上传。没有自动投稿授权时只保留本地素材。

## 视频边界

配音文本通过必剪在线接口合成（社区适配，可能变化）；音视频合成在本机 Concat 运行。固定片头按文本缓存，避免重复生成。字幕当前按句长估算时序，不声称逐字准确对齐。提供 MP4、SRT、WAV、口播、发布文案、输入快照和可编辑 Concat 工程。没有建立无人值守定时任务。

## 接入其他 Agent

STDIO 命令：`node <项目绝对路径>/mcp-server.mjs`。环境变量 `ARENA_URL=http://127.0.0.1:4173`。如果应用设置了 APP_API_TOKEN，给 MCP 设置同值的 ARENA_TOKEN；不要把令牌提交到Git。
